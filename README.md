# Swell Tracker
Created by Liam Barnes and Elias Ghiz

## Purpose
The purpose of this application is to be a surf forecasting and surf exploration tool. Users can navigate anywhere on the globe to view surf spots and see surf breaks up close, and they can also run forecasts to get a surf report at a location for the week. Surf forecasts include wave height, wave period, and wind information.

The application uses data from a [marine weather api](https://open-meteo.com/en/docs/marine-weather-api) and a general [weather forecast api](https://open-meteo.com/en/docs) to generate surf reports.

## Installation
Prerequisites: Node.js, pnpm

1. Clone the repository locally
2. Cd into the main directory of the app
3. Run `pnpm i` to install dependencies
4. Run `npm run dev` to start the development server.
5. Navigate to [https://localhost:3000/](https://localhost:300/) to view the application!
